# 💰 CoachFinanceBR

Uma aplicação web para **controle e organização das finanças pessoais**, criada com o objetivo de facilitar o acompanhamento de gastos, cartões e diferentes formas de pagamento em um único lugar.

🔗 **Acesse o projeto:** https://coachfinancebr.lovable.app/

---

## 📌 Sobre o projeto

O **CoachFinanceBR** nasceu a partir de uma necessidade pessoal: organizar melhor os gastos quando utilizamos **mais de um cartão de crédito**, além de despesas realizadas por Pix, débito e dinheiro.

Quando os gastos estão distribuídos entre diferentes cartões e formas de pagamento, pode ser difícil ter uma visão clara de quanto já foi gasto e quais despesas ainda estão por vir.

A proposta do projeto é justamente **centralizar essas informações**, tornando o acompanhamento financeiro mais simples e organizado.

---

## 🎯 Objetivo

O projeto foi desenvolvido com dois objetivos principais:

* Centralizar os gastos pessoais em um único lugar;
* Explorar o uso de **Inteligência Artificial no desenvolvimento de aplicações**.

Além de ser uma ferramenta para organização financeira, o CoachFinanceBR também representa uma experiência prática de aprendizado sobre novas formas de desenvolvimento utilizando IA.

---

## ✨ Principais funcionalidades

* 💰 Controle de despesas;
* 💳 Organização de gastos realizados em diferentes cartões;
* 📅 Controle de vencimentos;
* 🏦 Registro da origem dos gastos;
* 💵 Controle de despesas via Pix, débito e dinheiro;
* 📊 Centralização das informações financeiras;
* 📱 Interface voltada para facilitar o acompanhamento das despesas.
